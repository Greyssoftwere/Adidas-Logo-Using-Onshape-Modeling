# Adidas Logo CAD Model



This project is a 3D CAD model of the Adidas logo created using **Onshape**. The logo was made using Onshape's tools and then converted into a 3D model using extrusion.

The model consists of three separate parts representing the Adidas stripes. The final design was exported as an STL file for use in 3D modeling, visualization, or 3D printing applications.


Adidas_Logo.stl will contain the exported 3D model of the Adidas logo in STL format.

## Software Used

* **Onshape** — CAD modeling and sketching
* **STL** — 3D model export format


## Result

The final result is a 3D representation of the Adidas logo that can be viewed in Onshape or opened using software that supports STL files.
